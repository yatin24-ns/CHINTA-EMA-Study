# CHINTA-EMA-Study
We ran a modified pilot Ecological Momentary Analysis on an Indian academic sample. Aimed to find predictors between daily workload and fatigue and their recovery mediated (leisure quality and sleep quality) offset relationship. Both between/within person. Theoretical Study design, Predictor modelling, EMA deployment and development of the statistical pipeline was done from scratch.


 This was conducted as a Summer Internship Project at CHINTA, Kolkata.


 This is a storage repository rather a project repository and is not maintained.
